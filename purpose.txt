GitHub (https://github.com/) – крупнейший веб-сервис для хостинга IT-проектов и их совместной разработки. Веб-сервис основан на системе контроля версий Git. Ознакомиться с документацией по работе с GitHub можно на сайте GitHub Help (https://help.github.com/en) . Также GitHub содержит миллионы открытых проектов, которые можно использовать бесплатно. Основная задача Git – управление историей изменений проекта. Git и GitHub связаны, при этом можно использовать Git без GitHub, используя локальный репозиторий, не отправляя проект в интернет. Репозиторий – это хранилище проекта, управляемое Git. Рабочая директория – это обычные файлы проекта, с которыми разработчик работает (например непосредственно в VS Code). Рассмотрим некоторые команды в git. Clone – клонировать репозиторий с GitHub. Init – инициализировать новый локальный репозиторий. Add – добавить измененные файлы в индекс (stage). Commit – сохранить изменения в истории проекта, это снимок проекта в определённый момент времени. Каждый commit имеет уникальный идентификатор, автора, дату, информацию об изменениях. Хорошие сообщения commit должны кратко описывать выполненную работу. Также перед commit изменения должны быть сохранены в файле. Работы с git можно осуществлять через терминал, либо с помощью интерфейса (например, в VS Code).  Ветка (branch) – отдельная линия разработки проекта. Основная ветка обычно называется main. Ветки позволяют одновременно разрабатывать различные функции. Один разработчик может работать над авторизацией, другой над дизайном, третий исправлять ошибку. Когда разработка функции закончена, изменения можно объединить с main. Иногда Git не может автоматически объединить изменения, если была изменена одна и та же информация, возникает merge conflict.
